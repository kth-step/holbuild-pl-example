# holbuild programming languages metatheory example

This is an example project that uses
[holbuild](https://github.com/HOL-Theorem-Prover/holbuild)
to set up a failing HOL4 proof.

To build the project after installing `holbuild`:

```shell
holbuild build
```

See [this PDF](https://kth-step.github.io/plfm-course/module-1/exam.pdf)
for the background and tasks.
